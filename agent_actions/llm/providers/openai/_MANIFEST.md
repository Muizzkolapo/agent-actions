# OpenAI Provider Manifest

## Overview

Adapter for OpenAI APIs that differentiates tool/batch/online clients across the
project.

## Modules

| Name | Type | Description | Signals |
|------|------|-------------|---------|
| `batch_client.py` | Module | Batch client for uploading and monitoring OpenAI jobs. `STATUS_MAPPING` maps every status of the SDK's `Batch` into `BatchStatus`: `cancelling` is in flight, `expired` is failed. Each line's body takes the action's `vendor_params` (`OpenAIClient.VENDOR_PARAMS.apply_to_body`), `max_tokens` as `max_completion_tokens` (OpenAI refuses `max_tokens` on its reasoning models), and `temperature` only when the action sets one (a reasoning model's other than 1 is refused at preflight). | `llm.batch`, `llm.providers` |
| `compatible.py` | Module | One `OpenAIClient` subclass per row of `RUNTIME_PROFILES` (llamafile): default `base_url`, key placeholder for a runtime that takes no key, capabilities from the row. Registered as `compatible:<vendor>`. `endpoint_client(name)` builds an `EndpointClient` for a declared endpoint (`llm.config.endpoints`): its url, headers, timeout and credential (`env`; `command`, run from the project root once per command under a lock, again after `refresh_seconds` or once after a 401; or none; a non-Authorization auth header drops the SDK's `Authorization` unless `headers:` declares one), inherited `api_key`/`base_url` ignored, an action's `request_timeout` sent per request only when the action sets one (otherwise the endpoint's `timeout_seconds` governs), a reply that does not match the schema returned as `_parse_error`, every secret read registered with the redactor. `ENDPOINT_CAPABILITIES` refuses batch. An endpoint sends `max_tokens` under that name (`_max_tokens_key`). An endpoint's `Authorization`, written in any spelling as a header or as the credential header, goes under the SDK's exact `Authorization` key; where the credential travels in another header, the SDK's `Authorization` is omitted on the client and again on each request (`_request_headers`, sent as `extra_headers`), since openai 3.x looks for the omission only among a request's own headers. | `llm.realtime`, `validation.preflight` |
| `endpoint_probe.py` | Module | `probe_endpoint(name, model)`: one structured-output request to a declared endpoint for `--verify-keys`; the outcome is a kind: `refused` (401/403), `not_honoured` (a reply that is not the probe's object, or HTTP 400/422 whose text names `response_format` or `json_schema`), `rejected` (any other 400/422, with the server's text), `no_answer` (a reply with no text: a refusal or the token limit spent), `answered` (any other status), `unreachable`, `config` (the auth command failed); each is an error naming the endpoint, with a hint by kind. | `validation.preflight` |
| `client.py` | Module | Online OpenAI client supporting tool calls and streaming. Sends each action to its own `base_url` when the action sets one; `_client_options()` is the one place the SDK client's constructor kwargs come from, which a subclass extends; `_request_timeout_kwargs()` is the per-request timeout, which a declared endpoint narrows. `_max_tokens_key()` names the output limit: `max_completion_tokens` for OpenAI itself, `max_tokens` for a server at a `base_url` (a runtime profile included) or a declared endpoint. `VENDOR_PARAMS` takes every keyword of `chat.completions.create` but `stream_options`; a runtime profile or declared endpoint inherits it. An empty answer names its `finish_reason`; `length` is a `ResponseTruncatedError`. A `refusal` is quoted instead: a JSON call's record fails with it as `_parse_error` (logged as a warning), a text call raises it as a `VendorAPIError`. At import it builds the models of `ChatCompletion` (`build_sdk_models`), which the SDK may otherwise build on first parse, in several record threads at once. A JSON answer cut off at `length` is a parse error naming the stop reason (`cut_off_parse_error`), never repaired into a partial object; a text answer the limit stopped at an empty string is a `ResponseTruncatedError`, as one with no content is. | `llm.realtime`, `llm.providers` |
