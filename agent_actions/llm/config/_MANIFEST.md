# Config Manifest

## Overview

Vendor configuration helpers used by both batch and online connectors.

## Modules

| Name | Type | Description | Signals |
|------|------|-------------|---------|
| `endpoints.py` | Module | `parse_endpoints()` validates the `endpoints:` block of `agent_actions.yml` into `Endpoint` rows (base `url` or one `${ENV_VAR}`, `auth` by env or command, extra `headers`, `timeout_seconds`), refusing a name that is a built-in vendor or profile. `load_project_endpoints()` validates the block beside its reader (`ConfigManager.get_user_agents`) and replaces the per-project registry that `project_endpoints()` / `project_endpoint()` read; a refused block registers nothing. | `config.manager` |
| `prices.py` | Module | The `prices:` block of `agent_actions.yml`: what one million tokens of a model cost. `parse_prices()` validates it into `ModelPrice` rows (`input`, `output`, optional `cache_read`, `cache_write` and `batch_discount`, the share from 0 to 1 taken off a batch call), refusing an entry with every mistake it holds, each named by its key. `estimated_cost(prices, row)` prices one usage row, or returns no cost and the key the table lacks (`prices.<model>`, `prices.<model>.batch_discount`, `prices.<model>.cache_read`), so a caller never shows 0 for a cost it does not know. The framework ships no price. Read by `agac usage` only; a run does not read it. A refusal names `agent_actions.yml` (in its text and its `hint`), and a missing key also names the unknown keys beside it and each bad price of the entry. | `cli` |
| `runtime_profiles.py` | Module | `RUNTIME_PROFILES`: one measured row per named OpenAI-compatible runtime (llamafile). `wire_vendor()` maps a profile vendor, or a declared endpoint, to the vendor whose formats it speaks (`openai`). | `llm.providers.openai`, `llm.realtime`, `output.response`, `validation.preflight` |
| `vendor.py` | Module | Defines vendor profiles + defaults (timeouts, engines). `vendor_names()` is the one list of names `model_vendor` accepts (`VendorType` + `RUNTIME_PROFILES` + the project's declared endpoints); `NON_LLM_VENDORS` names the vendors that run no model; `ONLINE_ONLY_VENDORS` (tool, hitl) names those the pipeline always runs online, which every batch check skips. `VENDOR_CONFIGS` maps each `VendorType` to its config class; `api_key_env_var(vendor)` is the variable its key is read from (None when it takes none); `openai_model_reasons(model, reasoning_effort)` says whether an OpenAI model reasons on a request (the o-series and gpt-5 by prefix, snapshots and fine-tunes included, gpt-5-chat not; gpt-5.1 and later only with a reasoning_effort other than none), read by preflight's temperature check; `vendor_needs_api_key(vendor)` is the one rule expansion and preflight read (False for `agac-provider`, `ollama_local`, tool, hitl, a runtime profile with `api_key_required=False` such as `llamafile`, and a declared endpoint). | `llm.providers` |
