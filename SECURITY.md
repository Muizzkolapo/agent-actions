# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version only.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

1. Use GitHub's private vulnerability reporting in the repository Security tab.
2. Include: affected version, reproduction steps, impact, and any proof-of-concept.
3. We will acknowledge and triage as quickly as possible.

## Disclosure Process

- We validate and triage reports.
- We coordinate a fix and release timeline.
- We publish an advisory after a patch is available.
