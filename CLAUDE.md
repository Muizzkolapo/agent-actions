## Reply Style

Write every chat reply to the user in ASD-STE100 Simplified Technical English:

- Use short sentences: 20 words or fewer for an instruction, 25 or fewer for a description.
- Use the active voice.
- Write one instruction in one sentence.
- Use simple, common words. Use one word for one meaning.
- Put the most important information first.
- Use lists for steps and for groups of facts.
